# 997ICU · 工作有时，生活无价

[997icu.cn](https://www.997icu.cn/) 中文响应式首页。使用原生 HTML、CSS 与 JavaScript，无第三方运行依赖、字体请求或用户材料上传。

## 本地运行

需要 Node.js 20 或以上版本。在本目录执行：

```sh
npm run dev
```

访问 http://localhost:3000 。使用 `PORT` 环境变量可修改端口。无需执行 `npm install`。

```sh
npm run check
npm test
```

启动本地服务后，可运行 `npm run test:browser`，使用本机 Chrome / Edge 验证 5 种屏宽及主要交互，截图输出到 `.artifacts/`。可以通过 `CHROME_PATH` 指定浏览器可执行文件，通过 `TEST_URL` 指定待测地址。

## 页面功能

- 响应式导航、主题插画、健康与生活影响介绍。
- 实时工时计算器：每日实际工时 × 每周天数，对比每周 40 小时；按 4.345 周/月换算额外工作占据的完整天数。结果不等同于法律上的加班认定。
- 工时休息、加班报酬、维权时效三个法律信息标签页，支持方向键、Home、End。
- 全国人社政务服务平台、中国法律服务网和国家法律法规数据库外链，以及 WHO/ILO 研究来源。
- 证据清单对话框、浏览器本地勾选保存、UTF-8 文本下载、常见问题折叠。
- 跳转主要内容、键盘焦点、系统减少动画偏好、原生对话框焦点管理。

## 部署

静态主机或 Nginx 仅需发布以下文件至站点根目录：

```text
index.html
styles.css
app.js
favicon.svg
robots.txt
```

也可用 `npm start` 启动内置 Node 服务，再用反向代理提供 HTTPS。此服务仅允许访问上述公开文件，不会公开源目录中的其他文件。部署在域名根路径，资源引用使用绝对路径。

域名解析、HTTPS 证书、生产主机及需要时的备案须在实际托管环境配置；本项目未自动发布。请勿编造备案号，可在获得真实备案信息后补充页脚。

## 内容与上线核验

法律信息面向中国大陆一般劳动用工情形，页面注明标准工时与特殊工时的适用差异。

- 每日 8 小时、每周 40 小时：《国务院关于职工工作时间的规定》第 3 条。
- 每周至少休息 1 日、延长工时上限、法定例外、加班报酬：《劳动法》第 38、41—44 条。
- 一般仲裁时效与拖欠报酬特殊规则：《劳动争议调解仲裁法》第 27 条。
- 健康研究：WHO 2021-05-17 关于 WHO/ILO 长工时与缺血性心脏病、卒中研究的说明。

开发环境外网不可达，未实时确认外部平台当前可达性、具体投诉入口及法律现行版本。上线前应在可联网环境复核页面法律信息、官方域名、研究链接，以及当地办理渠道；平台入口并不保证全国各地都能直接在线受理同一种投诉。

清单勾选状态使用 localStorage 键 `997icu-evidence-v1`，仅保存在访问者浏览器，清理站点数据即可删除。没有统计脚本、后端投诉接口或账号系统。
